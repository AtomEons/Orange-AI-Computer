# Distribution Map

GitHub is the first wave and canonical object. Every later channel points to
GitHub. GitHub points to Atom Eons for the larger body of work.

## Wave Order

1. **GitHub:** repository front door, release, evidence ledger, manuals,
   security policy, discussions.
2. **X and LinkedIn:** one original technical post per owned account or page;
   replies carry proof details rather than repeating the launch.
3. **Practitioner communities:** Bun Show and Tell, Ollama, local AI, MCP,
   self-hosted, and agent-engineering communities with integration-specific
   posts.
4. **High-scrutiny communities:** Hacker News and LocalLLaMA with a runnable
   path, explicit affiliation, and active technical replies.
5. **International wave:** localized posts whose figures and boundaries remain
   identical to the English evidence ledger.
6. **Earned follow-through:** publish failed-install fixes, hardware matrices,
   external reproduction receipts, and compatibility improvements.

## Relevant Handles And Tags

Use a project handle only where its component is substantively demonstrated.
Potentially relevant: `@bunjavascript`, `@ollama`, `@huggingface`, GitHub,
Model Context Protocol, Tauri, Qwen, and Z.ai. A mention is not an endorsement.

Use at most one or two discovery tags per post. Suggested pool:
`#LocalAI`, `#OpenSource`, `#AIAgents`, `#MCP`, `#Bun`, `#Ollama`.

## Distribution Law

- Never buy engagement, use sockpuppets, or coordinate fake reactions.
- Never mass-DM strangers or send guessed-email campaigns.
- Do not paste identical copy across Reddit communities.
- Disclose affiliation.
- Do not ask for votes or stars.
- Pause a claim when a reproduction contradicts it; publish the repair.
- Technical replies outrank promotional frequency.

The goal is saturation through useful artifacts, translations, integrations,
and responsive engineering, not platform abuse.
