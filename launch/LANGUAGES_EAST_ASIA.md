**社区帖**

Æ Orange AI Computer 现已开源。它不是又一个让模型给自己打分的代理框架，而是一个本地优先的 AI 运维控制平面。核心原则很简单：模型不能为自己的工作出具可信证明，证明必须来自模型之外。确定性的 Bun 控制层约束流程；来源可追溯的记忆保留依据；Context Crystal 压缩运行上下文；Hermes 只在明确边界内执行；MCP 连接工具与系统；SHA-256 回执则为每条指定路径提供可复核、可重放的证明。

目前公布的都是有明确边界的测试结果，而非通用性能结论：Blue Bench 10/10；Context Crystal 5/5，并在 7,056,795 字节的留出语料库上达到最低 1,422.901x 的运行上下文比；AE Memory 23/23，MRR 0.9058。这些数字仅适用于所述测试条件，不代表所有模型、任务、硬件或工作负载。

**コミュニティ投稿**

Æ Orange AI Computerをオープンソースで公開しました。これは、モデルに自己採点させるための新しいエージェント基盤ではなく、ローカルファーストのAI運用コントロールプレーンです。基本原則は明快です。モデルは、自分の仕事を自分で認証できません。信頼できる証明は、モデルの外側に置く必要があります。決定論的なBun制御が処理を固定し、出典に裏付けられたメモリが根拠を保持します。Context Crystalは運用コンテキストを圧縮し、Hermesは明示された境界内だけで実行。MCPでツールやシステムを接続し、SHA-256レシートが指定された各パスに再検証・再現可能な証跡を残します。

現在公開している数値は、範囲を限定したテスト結果です。Blue Bench 10/10。Context Crystal 5/5、7,056,795バイトのホールドアウトコーパスで、運用コンテキスト比は最低1,422.901x。AE Memory 23/23、MRR 0.9058。すべてのモデル、タスク、ハードウェア、ワークロードに当てはまる普遍的な性能主張ではありません。

**커뮤니티 포스트**

Æ Orange AI Computer를 오픈소스로 공개합니다. 모델이 스스로 점수를 매기는 또 하나의 에이전트 프레임워크가 아니라, 로컬 우선 AI 운영 제어면입니다. 원칙은 분명합니다. 모델은 자신이 한 일을 스스로 인증할 수 없습니다. 신뢰할 수 있는 증명은 모델 바깥에 있어야 합니다. 결정론적 Bun 제어가 흐름을 고정하고, 출처에 근거한 메모리가 근거를 보존합니다. Context Crystal은 운영 컨텍스트를 압축하고, Hermes는 명시된 범위 안에서만 실행됩니다. MCP로 도구와 시스템을 연결하며, SHA-256 영수증은 지정된 각 경로에 다시 검증하고 재현할 수 있는 증거를 남깁니다.

현재 공개 수치는 범위를 명확히 제한한 시험 결과입니다. Blue Bench 10/10; Context Crystal 5/5, 7,056,795바이트 홀드아웃 코퍼스에서 운영 컨텍스트 비율 최소 1,422.901x; AE Memory 23/23, MRR 0.9058. 이는 모든 모델, 작업, 하드웨어, 워크로드에 적용되는 보편적 성능 주장이 아닙니다.
