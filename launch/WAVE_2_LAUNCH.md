# Wave 2: The Proof Is The Product

Most AI systems ask the same model to interpret a request, remember the
project, choose tools, execute work, narrate the result, and decide whether it
succeeded. Æ Orange AI Computer breaks that loop.

Models can reason, create, review, and dissent. Deterministic control owns
scope, policy, routing, execution state, and receipt authority. Work crosses a
typed path:

```text
human intent
  -> orange.order.v1
  -> source-backed memory and Context Crystal
  -> least-action model or tool lease
  -> bounded Hermes execution
  -> verification
  -> orange.report.v1
  -> SHA-256 receipt chain
```

The interface is replaceable. Models are replaceable. Source truth, project
continuity, operational contracts, and evidence survive.

## What Is Public Today

- A Windows-first, LLM-deployable preview package.
- A public proof ledger with named receipts and boundaries.
- Operator, architecture, memory, compression, installation, recovery, and
  skeptical-review manuals in Markdown and PDF.
- A deterministic control plane built primarily with Bun.
- One-computer and control-host-plus-AI-box topology designs.
