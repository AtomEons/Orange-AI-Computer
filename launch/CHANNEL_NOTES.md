# Æ Orange AI Computer Channel Notes

Canonical destination: <https://github.com/AtomEons/Orange-AI-Computer>

## Short Technical Description

Æ Orange AI Computer is a local-first AI operations control plane. Current
source, manuals, and selected receipts are public. Models can propose or perform
bounded work; deterministic code owns scope, policy, verification, and receipt
authority.

Public evidence is deliberately narrow: selected Atom Eons lab runs cover named
memory, compact-context, MCP, bounded-execution, and recovery paths. The
repository does not claim universal performance or whole-system green.

The existing deploy ZIP is a historical prerelease artifact and does not contain
the current source or Atomic Orange app source. A current-source package and
signed app installer remain open work.
