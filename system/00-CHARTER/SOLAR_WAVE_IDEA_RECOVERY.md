# Solar Wave Idea Recovery

This preserves the operator/system ideas recovered from the current Orange development arc so they cannot be flattened by context loss.

- Orange is an AI computer operating system, not a chat wrapper.
- The interface is not the intelligence.
- Full transcripts, sources, artifacts, and receipts live on disk; scarce RAM carries only the active workbench.
- Context Crystal and AtomSmasher target operational compression while preserving source hydration and semantic checksums.
- Memory answers what, why, source, confidence, contradiction, and supersession.
- Orange learns through predicted-versus-observed residuals, recurrence evidence, shadow evaluation, promotion, and rollback.
- OrangeBrain is the lead routing authority. Navigator preserves project scope. Models advise or execute under contracts; none becomes a hidden ruler.
- Little Navigators command bounded Hermes subsets without inheriting project authority.
- FLOW controls pressure and route changes. SwarmGate controls admission. SwarmSentinel detects duplication, drift, ghost work, evidence-free completion, and failure amplification.
- Æ Link gives every work object durable custody from offered through terminal.
- Solar Wave makes the work object proof-carrying across every organ.
- Æ Pulse is a persistent carrier whose unchanged signal is tiny and whose payload contains only state variations.
- Cup provides identity-based multipath reconnection instead of trusting one DNS name or IP address.
- Party Line is the cacheless disk-backed shared event current.
- Atomic Orange is the native conversational operator instrument.
- Cortex is held. AE Eyes wakes only when visual information gain justifies it.
- Research from women, Indigenous communities, Māori data-sovereignty work, Pacific-language adaptation, and global systems engineering retains attribution and enters a falsifiable promotion pipeline.
- Current awareness keeps local models informed about new tools without silently changing production behavior.
- Models and tools form a capability genome: interchangeable bodies must satisfy the same behavioral contract.
- One-computer and two-computer operation use identical protocols.
- No process start, HTTP response, generated file, receipt existence, or model prose is enough to prove operational capability.

## Complex Infinitus

Complex Infinitus is bounded unboundedness: Orange can add projects, nodes, models, agents, tools, memories, and research without allowing active complexity to grow without limit. Stable identities, typed references, law contracts, sparse workbenches, custody, semantic checksums, and disk lineage let the total system expand while each active decision remains small and inspectable.

The recovered north star is a proof-carrying, source-backed, self-stabilizing intelligence computer that improves through measured residuals without losing operator authority or semantic truth.
