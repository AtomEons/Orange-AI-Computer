## 120-Minute Sequence

### Minute 0-20: Truth Freeze

- Capture `git status --short` without cleaning it.
- Run semantic health and compute-fabric discovery.
- Record current host, route, endpoint, and receipt count.
- Stop unrelated automation that mutates the repo; do not stop required Orange organs.

### Minute 20-55: Full Verification


- Parse every red.
- Fix only evidenced root causes.
- Rerun focused tests for each changed module.

### Minute 55-80: Live Cross-Organ Proof

```powershell
bun run proof:orange:mcp
bun run proof:orange:hermes-live
bun run bench:memory-quality
bun run bench:context-crystal-quality

```

- Confirm receipt hashes.
- Confirm live route matches fabric selection.
- Confirm no model claims execution.

### Minute 80-100: Creative And Restart Proof

- Run one local FLUX artifact proof.
- Verify dimensions, nonblank pixels, model hashes, and artifact SHA-256.
- Trigger the hidden runtime task and confirm LastResult `0`.
- Confirm no visible PowerShell popup is created.

### Minute 100-115: ReadyForGit Dry Audit

- Search for secrets, machine-specific paths, and hard-coded addresses.
- Inventory untracked model weights and generated receipts.
- Confirm repository visibility intent.
- Do not commit, push, delete, or rewrite history during the audit.

### Minute 115-120: Go/No-Go

Go requires:

- zero unexplained verifier reds;
- live integrated proof green;
- no fake execution claims;
- restart continuity proven;
- exact not-green list accepted by the operator;
- release scope explicitly stated as internal or public.

Otherwise the correct verdict is **NO-GO with exact blockers**, not “mostly green.”
