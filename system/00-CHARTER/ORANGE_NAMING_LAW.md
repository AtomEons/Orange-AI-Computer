# Orange Naming Law

These names describe different layers and must not be collapsed.

| Canonical name | Meaning | Release posture |
|---|---|---|
| **AE Eyes** | OrangeFive's operational view system: visual ingestion, retrieval, grounding, description, proof, and memory integration. | Operational tool |
| **Cortex** | Photon, retinal, knot, invariant-pattern, and related experimental perception research reserved for Orange6. | Orange6 research; not an OrangeFive capability |
| **Atomic Orange** | The OrangeFive native operator product/app. | Product surface |

`OrangeEye` may remain in historical filenames or stable internal API symbols, but it is not the product name. New operator-facing text must say **Atomic Orange**. New photon/pattern work must say **Cortex**, never AE Eyes.

OrangeFive must not advertise Cortex as active, shipped, or required. OrangeFive uses **AE Eyes** for operational vision. Cortex begins with Orange6.
