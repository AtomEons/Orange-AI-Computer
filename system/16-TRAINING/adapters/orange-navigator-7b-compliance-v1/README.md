# Orange Navigator 7B Compliance V1

Purpose: teach the hot Qwen2.5-Coder 7B Navigator OrangeFive operational muscle memory without making the model the authority.

The active authority remains the Bun project lock, order/report contracts, deterministic router, Hermes leases, and receipts. The LoRA improves directness, Orange vocabulary, route selection, JSON discipline, and false-green refusal.

## Build and launch

```powershell
bun build-trainset.mjs
powershell -ExecutionPolicy Bypass -File launch-kaggle.ps1
```

Training uses a private Kaggle dataset and private GPU kernel. Promotion requires downloading the adapter, converting/attaching it to the exact Qwen2.5-Coder 7B base, and beating the current unadapted Navigator on held-out schema, directness, routing, false-green, latency, and project-lock tests.

No chain-of-thought is included in the corpus. No adapter is green merely because training finished.
