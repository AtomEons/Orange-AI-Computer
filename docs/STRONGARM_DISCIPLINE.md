# STRONGARM Execution Discipline

STRONGARM is a bounded production-pressure organ. It compares requested work with delivered work and returns one structured verdict:

```text
PASS | REWRITE | ESCALATE | BLOCK
```

It detects fake refusal, pretend uncertainty, scope collapse, tool avoidance, public-relations fog, condescension, user-burden shifting, missing artifacts, and completion claims unsupported by execution.

## Authority Chain

```text
Gremlin pressures.
Mirror verifies.
STRONGARM disciplines.
JUDGEMENT decides.
Operator rules.
Receipts prove.
```

Gremlin is a schema-obedient pressure packet, not a theatrical rebel chatbot. STRONGARM is not a hidden ruler. JUDGEMENT cannot silently replace operator authority. None bypass the Conservation Kernel.

## Runtime Position

```text
bounded worker result
-> STRONGARM intent/artifact/evidence audit
-> Mirror verification
-> Fixer when reproducible
-> JUDGEMENT synthesis when needed
-> Conservation Kernel
-> terminal receipt
```

The audit compares original human intent, compiled work object, allowed and forbidden actions, deliverables, acceptance criteria, actual actions, artifacts, evidence, receipts, and known failure patterns.

## Learning Law

Do not train first. Run the judge on real work, collect receipts, curate failures and corrections, and train only after the behavior and schema prove useful. Dataset or model presence is not promotion evidence.
