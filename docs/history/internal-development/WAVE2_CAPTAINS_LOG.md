# Æ Orange AI Computer Wave 2 Captain's Log

## Mission

Public documentation now presents one product identity: **Æ Orange AI
Computer**. Internal compatibility remains intact through machine ID `orange5`
and canonical root `C:\AtomEons\Orange5`.

## Brand Law

Æ Orange AI Computer challenges incumbents oranges-to-apples. The comparison is
useful work, accessible hardware, operator sovereignty, total system behavior,
and proof that survives inspection. It is never costume, borrowed language, or
an imitation of another lab's product.

The creative center is underestimated Good Will Hunting-style intelligence
translated into an original Orange idea: unexpected depth made practical,
clear, and available without elite hardware. Confidence must be earned through
completed crossings, adversarial review, receipts, and reproducible evidence.
Proof outranks hype. Originality outranks imitation.

## Public Documentation Decisions

- Public product naming uses Æ Orange AI Computer exactly.
- Legacy release names and public version labels are excluded from naming and
  sizzle.
- `orange5`, schema identifiers, commands, receipt paths, and the canonical root
  remain unchanged where machines require them.
- Atomic Orange is documented as the native operator surface, not the owner of
  intelligence or truth.
- Memory, governed learning, receipts, audit, and AtomSmasher production now have
  dedicated manuals.
- Bun runtime documentation uses `GUIDES/BUN_RUNTIME.md`.
- Markdown remains canonical; generated HTML, PDF, and manifest files are build
  artifacts.

## Evidence Posture

Public confidence is bounded. Every metric names its workload and receipt.
Process start, installation, configuration, HTTP status, file existence, model
output, and screenshots remain insufficient by themselves. A current exact-path
failure can narrow an older green result; a narrow success never promotes an
untested path.

## Captain's Watch

Future documentation work should reject four drifts:

1. legacy product naming returning through generated covers or copied prose;
2. benchmark numbers detached from denominators and receipts;
3. native UI claims based only on browser or backend proof;
4. learning claims that bypass recurrence, counterexamples, or rollback.

Wave 2 closes when the manual build succeeds from current Markdown and the
manifest records every canonical guide with source and artifact hashes.
