# Public Preview Truth

This release is intentionally published as a preview so installation can be tested on computers beyond the AtomEons two-node lab.

Known limits:

- Atomic Orange UI is not included in this headless Codex deploy ZIP.
- Model weights are acquired or adopted on the target machine and are not redistributed here.
- Missing credentials, denied administrator elevation, absent hardware, or upstream model/license removal cannot be repaired automatically.
- The current-awareness organ verifies primary bytes and timestamps, but its first live candidate-promotion decision still needs broader field evidence.
- Governed chat evidence tests pass, but exact-answer behavior remains model-dependent and fails closed as `needs_action` when the model drifts from evidence.
- Windows is the proven primary platform; other operating systems are not claimed ready.

These limits do not weaken hashes, receipts, rollback, or readiness truth. A target computer that cannot complete a required live probe remains visibly not ready.
