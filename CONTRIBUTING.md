# Contributing

Æ Orange AI Computer welcomes concrete failures, reproducible improvements,
hardware compatibility reports, and bounded integrations.

## The Useful Contribution Shape

1. Name the exact release or commit.
2. State OS, CPU, RAM, accelerator, Bun version, Ollama/model runtime, and
   one-computer or two-computer topology.
3. Include the exact command or structured order.
4. Attach sanitized output and the relevant receipt hash.
5. Separate observation from inference.
6. Propose the smallest change that can falsify the diagnosis.

## Claim Discipline

- Do not mark a path green because it started.
- Do not turn a fixture result into a production claim.
- Do not generalize a benchmark beyond its corpus, hardware, and contract.
- Do not include credentials, private model weights, user memory, or personal
  machine state.
- Preserve deterministic gates around model judgment.

Open an issue for a reproducible failure or a discussion for architecture and
research. Pull requests should explain the proof path and rollback surface.
